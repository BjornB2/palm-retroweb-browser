First public alpha release for Palm OS 4.0/4.1.

RetroWEB Browser can display inline GIF images. I could not find this feature
in other browsers that still run on the colour Palm IIIc.

- RetroWEB is the default home page.
- Entered HTTP and HTTPS URLs are loaded through retroweb.bjrno.com.
- Basic HTML rendering, bookmarks, history and forms.
- Inline GIF87a/GIF89a first-frame support.
- Progressive rendering and responsive navigation.

Install `RetroWEBBrowser-0.1.17.prc` using Palm Desktop, HotSync or another PRC
installer.
