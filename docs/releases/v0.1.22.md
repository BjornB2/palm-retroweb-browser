# 0.1.22

- Uses `http://retroweb.bjrno.com/?img=inline` as the default home page in
  both the RetroWEB and RetroModem browser profiles.
- Adds a Home page field under **Options > Preferences**.
- Stores the chosen home page separately for each profile and uses it at
  startup, from the Home menu command and from the Home button.
- Retains existing bookmarks, history and image preferences when upgrading
  from 0.1.21.
