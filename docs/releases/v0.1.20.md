# RetroWEB Browser 0.1.20

This alpha fixes menu selection while a page is loading. The menu could open
in earlier builds, but Palm OS consumed the selected item before the browser's
loading loop handled it.

Selecting a command now stops the current request and passes the command back
to the normal application event loop. Disconnect remains immediate. This keeps
navigation, bookmarks, settings and network commands responsive without
starting nested network requests.

Version 0.1.20 also includes the precise stylus scrolling and full-height page
viewport introduced in 0.1.19.

Install `RetroWEBBrowser-0.1.20.prc` using Palm Desktop, HotSync or another PRC
installer. Close RetroWEB Browser before replacing an installed copy.
