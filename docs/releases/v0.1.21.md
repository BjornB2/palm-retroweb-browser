# RetroWEB Browser 0.1.21

This release changes how application updates are packaged. Some Palm installers
refuse to replace an existing application database even when the creator ID,
database version and update flag are correct.

Version 0.1.21 therefore uses a versioned internal database name. Palm OS can
install it beside an older open copy and recognises it as the newer application
through its unchanged creator ID and higher database version. On first launch,
0.1.21 removes older application databases belonging to RetroWEB Browser.
Bookmarks, history and image preferences are stored separately and remain in
place.

This release also includes responsive menu selection during page loading,
precise stylus scrolling and the full-height page viewport.
