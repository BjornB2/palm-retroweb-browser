# RetroWEB Browser 0.1.19

This alpha improves scrolling on the Palm IIIc. The scrollbar now follows the
stylus position directly instead of turning every interaction into a full-page
jump. This makes it possible to position larger inline images more precisely.

The page viewport and scrollbar now also extend to the bottom of the 160 by 160
pixel display, removing the unused strip below the browser content.

The release retains the basic HTML renderer, bookmarks, history, forms,
progressive rendering and inline GIF first-frame support from 0.1.17.

Install `RetroWEBBrowser-0.1.19.prc` using Palm Desktop, HotSync or another PRC
installer. Close RetroWEB Browser before replacing an installed copy.
